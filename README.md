# EZA Design — Project Brain

This is a simple static web app for the EZA Design dashboard. It shows project cards, summary metrics, and a project list with stages, costs, margins, and deadlines.

## Files
- `index.html` — page structure and content
- `styles.css` — clean minimal styling with the brand palette
- `app.js` — sample projects and dashboard rendering logic

## How to open
1. Open the folder in VS Code.
2. Open `index.html`.
3. Right-click the file and choose "Open with Live Server" if you have the extension installed, or open it directly in a browser.
